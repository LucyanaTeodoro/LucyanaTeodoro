# Exemplo de briefing

Modelo simplificado preparado para o portfólio, derivado da primeira aplicação. Não substitui a especificação completa do curso.

| Campo | Informação |
| --- | --- |
| Tema | Mobilização, transferências e prevenção de quedas |
| Público | Estudantes da saúde, especialmente Fisioterapia e Enfermagem |
| Experiência | Diferentes níveis de formação |
| Duração | Três horas, incluindo prática |
| Modalidade | Presencial |
| Participantes | Aproximadamente 15 |
| Equipe docente | Uma professora |
| Infraestrutura confirmada | Macas, cadeiras e espaço para movimentação |
| Conferências locais pendentes | Quantidades, integridade e características dos equipamentos; recursos audiovisuais |
| Entregas desta aplicação | PPTX editável, materiais docentes e documentação de pesquisa |
| Decisão final | Revisão e aprovação expressa da professora |

Condições informadas, sugestões e pendências devem permanecer identificadas separadamente durante o desenvolvimento.
