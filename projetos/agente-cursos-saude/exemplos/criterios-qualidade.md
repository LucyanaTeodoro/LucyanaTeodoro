# Exemplo de critérios de qualidade

Recorte documental preparado para apresentar o funcionamento do projeto.

| Dimensão | Critério |
| --- | --- |
| Planejamento | Relacionar objetivos, público, duração, atividades e recursos disponíveis |
| Fontes | Não inventar referências; registrar fontes consultadas e limitações de acesso |
| Conteúdo | Diferenciar evidência, recomendação institucional e proposta pedagógica |
| Segurança | Identificar precauções e condições necessárias às atividades |
| Entrega | Gerar o formato solicitado e conferir o arquivo efetivamente salvo |
| Design | Conferir legibilidade, proporções e disposição dos elementos |
| Revisão | Combinar verificações técnicas com inspeção visual quando disponível |
| Privacidade | Utilizar casos fictícios ou desidentificados e contatos autorizados |
| Aprovação | Manter o material como rascunho ou em revisão até manifestação expressa |

Esses critérios orientam o trabalho. Sua presença na documentação não comprova, isoladamente, cumprimento em todas as entregas ou validação clínica do conteúdo.
